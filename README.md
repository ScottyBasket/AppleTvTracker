# Apple TV Tracker

## Run locally

Install [Node.js](https://nodejs.org/) 20.19+ or 22.12+, then from this project directory run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (by default, http://localhost:5173). These commands work in macOS Terminal and Windows PowerShell or Command Prompt.

To create a production build, run `npm run build`.

## Scripts

- `npm run dev` — start the development server with hot reload.
- `npm run build` — type-check and build for production.
- `npm run preview` — preview the production build locally.
- `npm run lint` — run Oxlint.
